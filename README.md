A one-line apology a smart speaker gives its owner after mishearing
"add milk to the list" as "add your mother-in-law to the group chat" —
written to `/output/entry.txt` by `main.py`. The joke lands on the
undercut: the device is sorry, but the mother-in-law is already typing.

Built for [make.fun](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729)
— referral code `6etrfz79`.

## Run it

```sh
python3 main.py
```

The program writes a single line (98 characters, no trailing newline) to
`$OUTPUT_DIR/entry.txt` (`/output` by default) and fails loudly if the gate
(1–140 characters) does not pass. Output is deterministic: repeated runs
produce identical bytes.
